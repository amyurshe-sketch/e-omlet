Redis ============================

sudo systemctl enable --now redis-server  -- включить

redis-cli PING  -- проверка "pong"

sudo systemctl stop redis-server  --  остановить  --  redis-cli shutdown  --  мягко

sudo systemctl restart redis-server  --  перезапуск

journalctl -u redis-server -f --  логи

Отключить автозапуск (Linux): sudo systemctl disable redis-server и sudo systemctl stop redis-server

-- Создаем базу данных
CREATE DATABASE myfastapi;

-- Создаем пользователя
CREATE USER fastapi_user WITH PASSWORD 'password123';

-- Даем права пользователю
GRANT ALL PRIVILEGES ON DATABASE myfastapi TO fastapi_user;

-- Выходим из psql
\q

sudo -u postgres psql -l  -Проверяем что база создалась, Должны увидеть в списке базу myfastapi

q -выход

еще раз входим, даем права на создание таблиц:

sudo -u postgres psql

-- Даем права на создание таблиц в базе myfastapi
GRANT ALL PRIVILEGES ON DATABASE myfastapi TO fastapi_user;

-- Даем права на схему public
GRANT ALL ON SCHEMA public TO fastapi_user;

-- Даем права на создание таблиц
GRANT CREATE ON SCHEMA public TO fastapi_user;

-- Выходим
\q
